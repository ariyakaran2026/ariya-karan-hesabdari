# ARIYA KARAN — Accounting & Trade Management System

نسخه 1.0 — داشبورد حرفه‌ای فارسی و راست‌چین برای حسابداری، انبارداری، بازرگانی، حمل و ترخیص.

## هدف نسخه اول
- داشبورد مدیریتی مدرن مطابق طرح تأییدشده
- حسابداری، خرید، فروش، خدمات، دریافت/پرداخت
- انبار و گردش کالا
- پرونده‌های انعطاف‌پذیر برای خدمات مختلف بازرگانی/حمل/ترخیص
- کاربران و سطح دسترسی
- گزارش‌ها و پشتیبان‌گیری
- آماده توسعه از آفلاین به شبکه داخلی و آنلاین

## اجرای توسعه
روی ویندوز، پس از نصب Node.js فقط:

```powershell
npm install
npm start
```

## ساخت EXE
```powershell
npm install
npm run build:win
```

خروجی در پوشه `dist` ساخته می‌شود. کاربر نهایی برای اجرای نسخه بسته‌بندی‌شده به Python، Node.js یا دیتابیس جداگانه نیاز ندارد.
